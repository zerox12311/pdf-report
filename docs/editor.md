# 編輯器功能（frontend）

Angular 20 SPA。兩個頁面：樣板列表（開啟/新增/刪除）與編輯器。編輯器可獨立使用，也可被宿主系統以 iframe 嵌入（見 [embed.md](embed.md)）。

> 本文只講功能行為；「哪個功能在哪個檔案」與「新增一種元件的檔案鏈」見 [CLAUDE.md](../CLAUDE.md) 架構區的前端導覽。

## 版面（仿 JasperReports）

- **頂列**：返回列表、樣板名稱（就地編輯）、「🔗 連接」對話框（iframe 嵌入碼＋render API 說明＋資料語法速查）、儲存（dirty 時顯示 `儲存 *`）。
- **左欄**：元件盤（分類：基本／報表；項目點擊或**拖曳到畫布**新增）＋大綱（節清單與元素樹：點選捲動定位、階層拖曳搬移/進出容器、複製/刪除）。
- **中欄**：設計／JSON／預覽 三分頁。
  - 設計：畫布（見下）。
  - JSON：樣板 JSON 直接編輯（貼上即套用）。
  - 預覽：走後端 render API 的真實 PDF（含資料 JSON 輸入區，與資料分頁共用）。
- **右欄**：屬性面板（依選取元素顯示）／資料分頁（見下）。

## 畫布

- 座標 pt、top-left 原點。zoom 30%–300%（工具列與觸控板 pinch，游標為錨點）。
- **尺規**：上/左兩條，左上角按鈕切換單位 PT → MM → IN，刻度跟縮放連動。
- **flow 節**顯示三條 band 標籤列（頁首 Page Header／內文 Detail／頁尾 Page Footer），拖曳標籤列調整 band 高度；**single 節**（獨立頁）為素面整頁。
- 頁面邊界（margin）以虛線輔助線顯示，是吸附目標，不影響渲染。
- 浮水印在畫布即時示意（平鋪/旋轉/圖層）。

### 元素操作

- 拖曳移動：**磁吸對齊**其他元素邊/中線與頁面邊界（紅色輔助線）；按住 Ctrl/⌘/Shift 暫停磁吸。**表格例外**：內容區不拖動表格（見表格章節）。
- 縮放三把手：右下角（雙向）、右緣（只調寬）、下緣（只調高）；縮放時吸附其他元素的邊與同寬/同高。表格縮放 = 全部欄寬列高等比。
- 拖到容器上：容器亮橘色外框提示，放開移入（座標轉容器相對）；容器內元素拖出邊界 = 移出到頂層；容器不能進容器。
- 鍵盤：方向鍵微調（Shift=10pt）、`Ctrl/⌘+C/X/V/D` 複製/剪下/貼上/副本、`Delete` 刪除、`Esc` 取消選取、`Ctrl/⌘+Z / Shift+Z / Y` 復原重做。
- 雙擊就地編輯：文字（多行 textarea 編輯內容）、資料欄位（編輯 **key 變數綁定**，非範例值；範例值在屬性面板改）、條碼（sample/content）、表格儲存格（文字格編輯文字、placeholder 格編輯 **key**；Enter 提交/Esc 取消）。
- **復原/重做**：所有結構性操作進歷史；400ms 內連續變更（拖曳、打字）合併為一步；上限 100 步。

### 右鍵選單（三套情境）

| 情境 | 項目 |
|---|---|
| 元素上 | 複製/貼上/建立副本（快捷鍵標示）｜上移/下移一層、移到最上/最下層｜✓ 置於浮水印之上（開關；容器子元素不顯示，跟隨容器）｜移出容器（僅容器內）｜刪除 |
| 表格儲存格上 | 上/下方插入列、左/右方插入欄｜刪除此列/此欄｜合併儲存格（需框選範圍）、取消合併（僅合併格）｜✓ 設為重複列｜✓ 自動換行｜清除儲存格內容 |
| 空白畫布 | 貼上（貼在滑鼠位置） |

點外面／Esc／捲動關閉；畫布區攔掉瀏覽器原生選單。

## 元件

| 元件 | 說明 |
|---|---|
| 文字 | 靜態文字＋行內插值 `{{key\|format}}`（畫布會代入範例資料預覽）；autoGrow 自動增高 |
| 資料欄位 | key 綁定＋範例值＋格式化（千分位/國字大寫/民國年/民國年長式） |
| 圖片 | 拖曳/點擊先落地**佔位元素**（不開檔案選擇器），來源在屬性面板三選一（優先序：動態 key > 固定連結 > 上傳）：「上傳圖片…」（PNG/JPEG，後端內容嗅探）／**固定圖片連結**（靜態 URL，渲染時抓取）／**動態圖片 key**（綁定渲染資料中的圖片 URL；範例 URL 供畫布預覽）。上傳會清掉 key 與 url；contain/stretch |
| 矩形／線條 | 框線色寬、矩形可填色 |
| 表格 | 見下 |
| 條碼 | code128/code39/ean13/qr；key 綁定或靜態值；可顯示人讀文字；預設「置於浮水印之上」 |
| 超商三段條碼 | 元件盤快捷（element-factory）：一次生成**三個普通 Code39 元素**＋標籤，非獨立元素類型，引擎無特殊處理 |
| 容器 | Frame：子元素相對座標、跨頁 keep-together、標題、框線/底色；限一層 |

共通：條件顯示（visibleKey/Op/Val，隱藏保留版面空間）、置於浮水印之上（aboveWatermark）。文字類共通樣式：字型（內建黑體/明體/等寬＋使用者匯入字型）、字級、顏色、對齊、行高、粗體、外框、底色、內距。

## 表格（Word/Excel 式操作）

- **選取**：點格 = 選表格＋選格；**按住拖曳 = 框選範圍**（同 Excel）；Shift+點選 = 從錨點框選。游標在內容區顯示 `cell`。
- **移動**：選取後左上角出現 **✥ 手柄**（Word 慣例），拖手柄才移動表格。
- 欄寬/列高：選取後格線上出現拖曳分隔線；屬性面板可直接輸入每欄/列數值；表格整體寬高唯讀（= 加總）。
- 列/欄數：屬性面板數字輸入（尾端增刪）或右鍵選單指定位置插入/刪除（合併格跨度自動調整、重複列索引自動推移）。
- **合併儲存格**：框選 → 合併；不可跨重複列/群組列邊界（重複列內只能左右合併）。
- **逐格樣式**（單格或**框選範圍批次套用**）：水平對齊（左/中/右）＋垂直對齊（上/中/下）＝九點對齊、粗體、字級（0=用表格）、文字顏色、背景色（色票直出＋×還原）、自動換行。
- **逐格框線**：上/下/左/右框線 toggle（亮=顯示中；共用線兩側鏡射，兩側都關才消失）、所有框線/外框線/內框線/無框線、**╲左斜線/╱右斜線**（劃掉未使用欄位）。表格框線寬 0（框線透明）時畫布以虛線輔助顯示。
- **儲存格類型**：靜態文字（支援行內插值）／資料欄位（key＋範例＋格式）／圖片（contain 縮進格內，不撐列高；上傳／固定連結／**key 綁定動態圖片 URL** 三選一——重複列內用相對 key，每列可不同圖）／**條碼**（類型 code128/code39/ean13/qr、key 綁定或靜態值、人讀文字；重複列內用相對 key，每列各自的條碼——用表格排版條碼的場景）。
- **自動換行**：勾選後內容超寬換行、該列列高渲染時自動延伸（畫布示意換行但列高不變）；未勾 = 單行裁切加「…」。
- **重複列**：某列依陣列資料展開；群組（groupBy＋群組首/尾列、$gsum/$gcount/$gavg）；畫布以藍/綠底色標示重複列/群組列。變更重複列位置時已綁 key 的儲存格不會自動搬移（面板有警告）。

## 資料分頁（右欄）

- 貼上預計 POST 的資料 JSON（與預覽分頁共用）；也可由樣板自動產生範例資料。
- JSON 以樹狀 key 顯示，**拖曳到畫布**：scalar → 生成資料欄位；陣列 → 生成重複表格（欄位自動展開）。
- 拖 key **到既有表格儲存格**：直接替換該格綁定（在重複列上自動轉相對 key）。
- 元件盤「圖片」「條碼」拖到儲存格：該格變成對應類型（圖片為佔位、條碼帶元件盤預設值），細節在屬性面板調整。
- **畫布上既有的圖片/條碼元素**也可直接拖進儲存格：拖曳時目標格高亮，放開後該格**繼承來源設定**（圖片的上傳/固定連結/動態 key；條碼的類型/綁定/人讀文字），原元素移除、選取跳到該格。
- 底部掛資料語法速查（可折疊）：插值語法、格式化對照、`$` 函式一覽。

## 節（Sections）

- 文件 = 有序節清單。`flow` 節：頁首/頁尾 band＋內容自動分頁；`single` 節：獨立一頁。
- 每節可覆寫紙張（預設清單：A4/A5/A3/B5/B4/Letter/中一刀 241×140mm（台灣三聯單/連續報表紙規格）/熱感 80mm（POS 熱感印表機紙捲），或自訂 mm）與方向。
- 每節浮水印模式：跟隨文件／不顯示／自訂。
- 大綱中新增/排序/刪除節（至少留一節）；跨節複製貼上可用。

## 浮水印（文件層＋節覆寫）

文字或資料綁定（key 有值時取代文字，例：status=作廢）、字級、顏色、旋轉角度（滑桿）、滿版平鋪（水平/垂直間隔）、圖層（內容下方/上方）。圖層為上方時，勾了「置於浮水印之上」的元素仍蓋在浮水印之上。

## 固定範圍數值的輸入

旋轉角度等固定範圍數字用「滑桿＋數字輸入」組合。
