# 編輯器功能（frontend）

Angular 20 SPA。兩個頁面：樣板列表（開啟/新增/刪除）與編輯器。編輯器可獨立使用，也可被宿主系統以 iframe 嵌入（見 [embed.md](embed.md)）。

> 本文只講功能行為；「哪個功能在哪個檔案」與「新增一種元件的檔案鏈」見 [CLAUDE.md](../CLAUDE.md) 架構區的前端導覽。

## 版面（仿 JasperReports）

- **頂列**：返回列表、樣板名稱（就地編輯）、「🔗 連接」→ **API 說明**對話框（分「後端 API」「前端嵌入」兩分頁，各可複製整份純文字）、儲存（dirty 時顯示 `儲存 *`，存檔成功後 * 消失）。**未儲存離開保護**：dirty 時返回專案/上一頁/站內導航會先跳確認（留在編輯器／放棄變更並離開）；關閉或重整瀏覽器則觸發瀏覽器原生提醒。
- **左欄**：元件盤（分類：基本／報表；項目點擊或**拖曳到畫布**新增）＋大綱（**目前節**的元素樹：點選捲動定位、階層拖曳搬移/進出容器、複製/刪除）。節/獨立頁的切換與管理在「頁面導覽面板」（見「節」章節）。
- **中欄**：左側「設計／樣板JSON／預覽」三個檢視分頁，右側獨立放「✓ 驗證」（與檢視分頁以分隔線區隔，屬設定性質）。
  - 設計：畫布（見下）。分頁按鈕內有**即時渲染開關**——開（藍）= 畫布把 `{{key}}` 代入範例資料；關（灰）= 顯示變數原文，一眼看出哪裡是變數（兩態下插值段都有淡黃底）。
  - 樣板JSON：**樣板**的 JSON 直接編輯（貼上即套用）；命名特別標「樣板」以免與資料 JSON 混淆。
  - **JSON 輸入區都是程式碼編輯器**（CodeMirror：語法上色、行號、括號配對/自動閉合、壞 JSON 即時紅線與行號燈號、Tab 縮排、**自動排版**（右上角按鈕或 Shift+Alt+F；JSON 有誤時按鈕短暫變紅、不動內容））——樣板JSON、資料分頁、預覽的資料 JSON、驗證分頁的測試資料四處共用同一元件（`shared/json-editor.component.ts`）。
  - 預覽：走後端 render API 的真實 PDF（含資料 JSON 輸入區，與資料分頁共用）。**後端的渲染警告會列在輸入區下方**（資料缺 key、圖片抓取失敗這類不擋出 PDF 的問題）——不顯示的話，設計者只會看到一張默默少了東西的單據。
  - 驗證：定義輸入資料的 schema 驗證（見下）。
- **右欄**：屬性面板（依選取元素顯示）／資料分頁（見下）。右欄僅在設計分頁顯示；在「資料」分頁時**點畫布元素會自動切回「屬性」**（從資料分頁拖 key 生成元件則保留在資料分頁，方便連續拖多個）。

## 畫布

- 座標 pt、top-left 原點。zoom 30%–300%（工具列與觸控板 pinch，游標為錨點）。
- **尺規**：上/左兩條，左上角按鈕切換單位 PT → MM → IN，刻度跟縮放連動。切換單位會**連動屬性面板的幾何輸入欄位**（元素 <div class="sub">文件浮水印（各節預設）</div>/Y/寬高、節頁首/頁尾高度、頁面邊界）顯示與輸入該單位、標籤同步顯示單位；模型永遠存 pt（1in=72pt=25.4mm，反算捨到 2 位）。
- **flow 節**顯示三條 band 標籤列（頁首 Page Header／內文 Detail／頁尾 Page Footer），拖曳標籤列調整 band 高度；**single 節**（獨立頁）為素面整頁。
- 頁面邊界（印刷邊界）：藍色虛線輔助線＋吸附目標，**不影響渲染**（元素仍可放邊界外）。設定方式三選一：屬性面板「文件層級」的 **Word 式預設**下拉（標準 72pt／窄 36pt／中等／寬／無邊界／自訂）、上下左右數值欄位、或**直接拖曳尺規上的藍色三角標記**。新樣板預設給「標準」邊界（讓一開始就看得到、可調）。
- **允許匿名渲染**（屬性面板最底部的「⚠ 危險區」，預設關）：開啟後此樣板的 render API 可不帶憑證呼叫（宿主前端直接渲染）；勾選後面板顯示風險提示（任何拿到樣板 id 的人都可渲染、靜態內容與範例值會出現在 PDF）。僅影響渲染，樣板讀寫仍要憑證（見 docs/api.md）。
- 浮水印在畫布即時示意（平鋪/旋轉/圖層）。

### 元素操作

- 拖曳移動：**磁吸對齊**其他元素邊/中線與頁面邊界（紅色輔助線）；按住 Ctrl/⌘/Shift 暫停磁吸。**表格例外**：內容區不拖動表格（見表格章節）。
- 縮放三把手：右下角（雙向）、右緣（只調寬）、下緣（只調高）；縮放時吸附其他元素的邊與同寬/同高。表格縮放 = 全部欄寬列高等比。
- **畫布縮放**：分頁列的 −/＋、點百分比重設 120%、`⇔` 符合寬度（整張紙縮到剛好放進可視區）。載入時若整張紙塞不進畫布會自動套用符合寬度（放得下就不動使用者的設定）——嵌在窄 iframe 裡預設 120% 會看不到整張紙。
- **旋轉**：**Figma 式**——選取單一元素後，滑鼠移到**四角外側**游標變旋轉箭頭，拖曳即繞中心旋轉（Shift 吸附 15°）；不顯示常駐按鈕。也可用屬性面板「旋轉（°）」輸入/scrub。順時針；純視覺（版面仍以未旋轉框計算），畫布與 PDF 同方向。
- 拖到容器上：容器亮橘色外框提示，放開移入（座標轉容器相對）；容器內元素拖出邊界 = 移出到頂層；容器不能進容器。
- 鍵盤：方向鍵微調（Shift=10pt）、`Ctrl/⌘+C/<div class="sub">文件浮水印（各節預設）</div>/V/D` 複製/剪下/貼上/副本、`Delete` 刪除、`Esc` 取消選取、`Ctrl/⌘+Z / Shift+Z / Y` 復原重做。
- 雙擊就地編輯：**文字（Word 式富文字編輯，見下）**、條碼（sample/content）、表格文字格（同 Word 式編輯；Enter 提交/Esc 取消）。資料綁定一律用文字內容裡的 `{{key|格式}}` 插值（例：`產品:{{name}}`），畫布會以資料面板的範例資料代入、插值段以淡黃底標示。
- **文字的 Word 式編輯**：雙擊進入 contenteditable，元素上方浮出工具列——選取一段文字後按 **B**（粗體）／**I**（斜體）／色票（9 色）／⌫（清除選取樣式），⌘/Ctrl+B、⌘/Ctrl+I 快捷鍵可用；Enter 換行、⌘/Ctrl+Enter 或點外面提交、Esc 取消。存檔時序列化成行內標記 `[b]…[/b]`／`[i]…[/i]`／`[c=#rrggbb]…[/c]` 存進 `content`（語法見 docs/engine.md；屬性面板的內容欄顯示原始標記、可手寫任意色值）。畫布即時渲染各段樣式。「整段全粗」收斂回元素粗體；元素粗體下「局部取消粗體」會自動把元素粗體下放成各段的 `[b]` 標記（引擎語意是元素粗體或 span 粗體疊加，無法表達局部取消）。**表格 text 儲存格同一套**：設計模式雙擊 text 格進入同款編輯器（工具列浮在格子上方），序列化存進 `value`、儲存格粗體/斜體同樣做收斂/下放；填寫（fill）模式維持純文字輸入。
- **復原/重做**：所有結構性操作進歷史；400ms 內連續變更（拖曳、打字）合併為一步；上限 100 步。
- **多選**（頂層元素）：Shift+點選加選/移除；畫布空白處拖曳 **框選**（Shift 拖曳=加選）。多選時每個元素顯示紫框、不顯示縮放把手。多選可一起拖曳移動、`Delete` 一起刪除。
- **對齊/分佈**：多選 2+ 元素時，設計分頁工具列出現對齊列（左/水平置中/右、頂/垂直置中/底，相對選取整體 bounding box）；3+ 元素多**水平/垂直等距分佈**（中心等距）。鎖定元素跳過。
- **數值欄位拖曳調整**（Figma 式 scrub）：屬性面板的數值標籤（<div class="sub">文件浮水印（各節預設）</div>/Y/寬/高、圓角統一與四角）游標會變 ↔，按住左右拖曳即可增減；用 Pointer Lock 鎖定指標，可一直往同方向拖（無限滾動），按住 Shift 加速 ×10。點輸入框本身仍是正常打字。
- **鎖定/隱藏**（大綱每個元素的 🔓/👁 圖示切換）：鎖定＝畫布不可選/拖（只能從大綱操作，不影響渲染）；隱藏＝設計與渲染都不顯示（保留版面空間，與條件顯示同閘門）。

### 右鍵選單（三套情境）

| 情境 | 項目 |
|---|---|
| 元素上 | 複製/貼上/建立副本（快捷鍵標示）｜上移/下移一層、移到最上/最下層｜✓ 置於浮水印之上（開關；容器子元素不顯示，跟隨容器）｜移出容器（僅容器內）｜刪除 |
| 表格儲存格上 | 上/下方插入列、左/右方插入欄｜刪除此列/此欄｜合併儲存格（需框選範圍）、取消合併（僅合併格）｜✓ 設為重複列｜✓ 自動換行｜清除儲存格內容 |
| 空白畫布 | 貼上（貼在滑鼠位置） |

點外面／Esc／捲動關閉；畫布區攔掉瀏覽器原生選單。

## 元件

| 元件 | 說明 |
|---|---|
| 文字 | 靜態文字＋行內插值 `{{key\|format}}`（畫布會代入範例資料預覽）＋**行內樣式標記**（部分文字粗體/斜體/變色，Word 式雙擊編輯）；autoGrow 自動增高（畫布仍照**設計高度**畫，角落標 `↕`；實際長多高與下方元素被推多少由引擎算，看預覽分頁） |
| 圖片 | 拖曳/點擊先落地**佔位元素**（不開檔案選擇器），來源在屬性面板三選一（優先序：動態 key > 固定連結 > 上傳）：「上傳圖片…」（PNG/JPEG，後端內容嗅探）／**固定圖片連結**（靜態 URL，渲染時抓取）／**動態圖片 key**（綁定渲染資料中的圖片 URL；範例 URL 供畫布預覽）。上傳會清掉 key 與 url；contain/stretch |
| 矩形／線條 | 框線色寬、**線型**（實線/虛線/點線，裁切線/騎縫線用）；矩形可填色、選**形狀**（矩形/橢圓·圓）＋**圓角**（Figma 式：選取時畫布四角有把手可拖曳調整——四角一起變；屬性面板統一輸入框，四角不同時顯示「混合」，可展開分別設定左上/右上/左下/右下） |
| 表格 | 見下 |
| 條碼 | code128/code39/ean13/qr；key 綁定或靜態值；可顯示人讀文字；預設「置於浮水印之上」 |
| 超商三段條碼 | 元件盤快捷（element-factory）：一次生成**三個普通 Code39 元素**＋標籤，非獨立元素類型，引擎無特殊處理 |
| 容器 | Frame：子元素相對座標、跨頁 keep-together、標題、框線/底色；限一層 |
| 重複區塊 | 見下（List／子表單）：綁陣列 key，內含「一筆」的自由版面，每筆蓋一次往下堆；可再巢狀一層做子明細 |

共通：條件顯示（visibleKey/Op/Val，隱藏保留版面空間）、置於浮水印之上（aboveWatermark）。文字類共通樣式：字型（內建黑體/明體/等寬＋使用者匯入字型）、字級、顏色、對齊、行高、粗體、**斜體**（整個元素；text 另可用 `[i]` 標記做局部）、底線、外框、底色、內距。斜體為預產生的假斜體字型變體；匯入字型無斜體變體、以正體呈現。

## 表格（Word/Excel 式操作）

- **選取**：點格 = 選表格＋選格；**按住拖曳 = 框選範圍**（同 Excel）；Shift+點選 = 從錨點框選。游標在內容區顯示 `cell`。
- **移動**：選取後左上角出現 **✥ 手柄**（Word 慣例），拖手柄才移動表格。
- 欄寬/列高：選取後格線上出現拖曳分隔線；屬性面板可直接輸入每欄/列數值；表格整體寬高唯讀（= 加總）。
- 列/欄數：屬性面板數字輸入（尾端增刪）或右鍵選單指定位置插入/刪除（合併格跨度自動調整、重複列索引自動推移）。
- **合併儲存格**：框選 → 合併；不可跨重複列/群組列邊界（重複列內只能左右合併）。
- **逐格樣式**（單格或**框選範圍批次套用**）：水平對齊（左/中/右）＋垂直對齊（上/中/下）＝九點對齊、粗體、斜體、字級（0=用表格）、文字顏色、背景色（色票直出＋×還原）、自動換行。
- **逐格框線**：上/下/左/右框線 toggle（亮=顯示中；共用線兩側鏡射，兩側都關才消失）、所有框線/外框線/內框線/無框線、**╲左斜線/╱右斜線**（劃掉未使用欄位）。表格框線寬 0（框線透明）時畫布以虛線輔助顯示。
- **儲存格類型**：文字（含 `{{key|格式}}` 插值——重複列相對 key、`$row`/`$gsum` 等都支援）／圖片（contain 縮進格內，不撐列高；上傳／固定連結／**key 綁定動態圖片 URL** 三選一——重複列內用相對 key，每列可不同圖）／**條碼**（類型 code128/code39/ean13/qr、key 綁定或靜態值、人讀文字；重複列內用相對 key，每列各自的條碼——用表格排版條碼的場景）。
- **自動換行**：勾選後內容超寬換行、該列列高渲染時自動延伸（畫布示意換行但列高不變）；未勾 = 單行裁切加「…」。
- **重複列**：某列依陣列資料展開；群組（groupBy＋群組首/尾列、$gsum/$gcount/$gavg）；畫布以藍/綠底色標示重複列/群組列。變更重複列位置時已綁 key 的儲存格不會自動搬移（面板有警告）。

## 重複區塊（List／子表單）

自由版面的「重複帶」——相對表格重複列（欄格式），重複區塊是**自由擺放的一筆版面**，每筆資料蓋一次往下堆。做 JasperReports 式的一對多／子報表。

- **綁定**：屬性面板設「資料陣列 key」（例 `orders`）＋筆間距 `gap`＋無資料範例筆數。**筆間距預覽**：調整 gap 時（拖曳標籤或聚焦輸入框），畫布出現半透明的「第 2、3 筆」示意，看得出每筆落點；放開/離開欄位即消失。畫布藍色虛線框；**key 標籤浮在框外上緣**，選取該區塊（或其內的任何子元素）或 hover 時顯示，不與內容重疊；未綁 key 時紅字常駐提示。框的「高」＝**一筆的高度**。
- **內容**：選取重複區塊後從元件盤新增元素（或拖入）直接加進「一筆」的版面；子元素座標相對區塊左上角。子元素的 key **相對當筆陣列元素**（例 `name`、`qty`）；因每筆共用同一份版面，欄位放在同一 x 就天然對齊成欄。
- **拖進拉出（同容器）**：重複區塊視同「帶 key 的容器」——畫布上既有元素可拖進/拖出，落點的容器亮橘框提示。三種方向都通：頂層↔區塊、外層區塊↔內層子明細（在同一外層內即可往內拖，不必先繞到最外層）；座標在絕對↔相對間自動換算。
- **巢狀（子明細，上限兩層）**：把另一個「重複區塊」放進來（元件盤選取外層區塊時點擊、或拖到外層區塊上），綁子陣列 key（例 `lines`）→ 外層每筆底下依子陣列展開。畫布以 teal 色框區分（key 標籤同樣浮在框外、選取/hover 顯示）。子明細內用 **`$parent.欄位`** 取外層當筆（例 `$parent.orderNo`）；全域彙總 `$sum(路徑)` 仍對整份資料。
- **版面慣例**：巢狀子明細應放在外層固定欄位的**下方**（固定欄位在上、明細在下）。固定欄位若被放到子明細框下方，渲染時明細會接在固定欄位之後（不重疊），但畫布與渲染的相對位置會與直覺不同——建議照慣例擺。
- **分頁**：每筆（及子明細每筆）是不可分割的原子，只在原子之間斷頁；外層某筆的子明細很長時會自動跨頁接續（外層那筆不整塊 keep-together）。單一原子若比整頁還高 → 渲染警告（`<div class="sub">文件浮水印（各節預設）</div>-Render-Warnings`，strict 模式 422）、不靜默裁切。

- **新增元件的落點**：點元件盤時放在內容區既有元素的下方；排滿之後改以階梯狀錯開並避開已佔用的座標（不會全部疊在同一點）。拖曳則落在放開的位置。

## 資料分頁（右欄）

- 貼上預計 POST 的資料 JSON（與預覽分頁共用）；也可由樣板自動產生範例資料（含表格重複列與重複區塊的巢狀陣列——`orders[].lines[]` 這類兩層結構會一併產出，讓子表單一開始就有東西可預覽）。
- **這份 JSON 跟著樣板存檔**（schema 的 `sampleData`，存原文以保留排版；引擎完全忽略，正式渲染一律用宿主 POST 的 data）。改動會標記未存檔，重新整理後原樣回來。
- 自動產生的範例資料**型別與「偵測欄位」一致**：偵測判為數字的欄位（格式化為千分位/國字大寫，或被 `$sum()` 引用）產出的就是數字，所以「用範例資料填入」的結果過得了自己偵測出來的驗證規則。
- JSON 以樹狀 key 顯示，**拖曳到畫布**：scalar → 生成 `{{key}}` 插值文字；陣列 → 生成重複表格（欄位自動展開成 `{{欄位}}` 文字格）。
- 拖 key **到既有表格儲存格**：直接替換該格綁定（在重複列上自動轉相對 key）。
- **畫布怎麼呈現資料**：文字插值用貼上的資料實際值（取不到保留 `{{key}}` token 提示、一眼看出沒綁到）；插值段淡黃底標示動態部分；重複列／群組列的相對 key 會補上陣列前綴、以**第一筆**呈現。畫布刻意只畫一列（設計面板不是輸出預覽，比照 JasperReports 的 detail band）——展開幾列、跨頁怎麼切看預覽分頁的真實 PDF。
- 元件盤「圖片」「條碼」拖到儲存格：該格變成對應類型（圖片為佔位、條碼帶元件盤預設值），細節在屬性面板調整。
- **畫布上既有的圖片/條碼元素**也可直接拖進儲存格：拖曳時目標格高亮，放開後該格**繼承來源設定**（圖片的上傳/固定連結/動態 key；條碼的類型/綁定/人讀文字），原元素移除、選取跳到該格。
- 底部掛資料語法速查（可折疊）：**只列語法本身**（插值／格式／`$` 函式的標籤），點任一個以 modal 顯示說明、範例與可複製的語法。

## 驗證分頁（輸入資料 schema）

定義宿主 POST 進來的 `data` 的驗證規則，綁在樣板上（存 `TemplateDoc.validation`）、可開關。用途：擋掉宿主漏填/型別錯的資料。

- **總開關**：關閉（預設，舊樣板亦然）→ 完全跳過；開啟 → 正式渲染（`/templates/:id/render`）在渲染前先驗，不過回 422、**不產生 PDF**（見 [api.md](api.md)）。**僅正式渲染套用，預覽/adhoc 不套**。
- **混合模式（自動推導＋手動微調）**：
  - 「🔍 從樣板偵測欄位」：掃樣板所有資料綁定（文字 `{{key}}` 插值、條碼/圖片 key、表格重複列 → `items` 陣列＋`items[].欄位`、重複區塊 → 綁的陣列＋`陣列[].子欄位`（巢狀子明細遞迴成 `orders[].lines[].欄位`）），**合併補新**到欄位表——只補表中還沒有的 path，已存在的（含手動微調）原樣保留（偵測可重複按）。排除 `$page` 等引擎保留字。型別會依綁定推斷（金額格式 `comma`/`twUpper` → 數字、重複列 key → 陣列，其餘 `任意`）；並解析全域彙總 `$sum/$avg/$count(路徑)` → 補出被引用的陣列與欄位（被 `$sum`/`$avg` 加總的欄位升級為數字，即使只出現在彙總內、畫面沒直接顯示也偵測得到）。
  - 手動：「＋ 手動新增欄位」、逐列改路徑/必填/型別、刪除。
- **欄位規則**：`必填`（存在且非空——字串去空白非空、陣列長度 > 0、數字/布林存在即可含 `0`/`false`）＋`型別`（任意/字串/數字/布林/陣列/物件；`數字` 嚴格，`"48000"` 字串判不過）。路徑語法：巢狀 `.`（`school.name`）、陣列逐元素 `[]`（`items[].amount`，對每筆檢查；陣列缺/空時交給該陣列自己那條報）、只寫陣列名檢查陣列本身。
- **測試區**：貼 `data` JSON（可「用範例資料填入」）→ 打 `POST /api/validate` 當場驗、列出哪欄不過（不渲染）。與正式渲染守門共用同一後端驗證器（唯一權威），忽略總開關。「用範例資料填入」**優先帶入「資料」分頁那份 JSON**（該分頁是空的或壞 JSON 才由樣板欄位合成）——兩邊各產一份的話，驗證過了也不代表實際出單會過。
- 已知取捨：偵測用 path 比對合併，手動刪掉「偵測來的」欄位後，下次按偵測會再出現（無刪除記憶）。

## 節（Sections）

- 文件 = 有序節清單。`flow` 節：頁首/頁尾 band＋內容自動分頁；`single` 節：獨立一頁。新增 flow 節預設給頁首 60／頁尾 40 pt 的可用 band（避免 band 顯示卻無空間）；band 高度歸零時屬性面板會提示。
- 每節可覆寫紙張（預設清單：A4/A5/A3/B5/B4/Letter/中一刀 241×140mm（台灣三聯單/連續報表紙規格）/熱感 80mm（POS 熱感印表機紙捲），或自訂 mm）與方向。
- 每節浮水印模式：跟隨文件／不顯示／自訂。
- **頁面導覽面板**（HackMD 式，位於左欄與畫布之間）：平常縮成一條細 bar（顯示節數），點擊展開為節/獨立頁的**垂直清單**——順序號由上到下＝文件前到後（一眼看出上下），多節捲動不擠。點某節＝切換編輯；未釘選時切完或點面板外面自動收回（peek 浮層，不推版面），**📌 釘選**則常駐佔版面。可**拖曳重排**順序、hover 顯示 **✕ 刪除**（確認後連元素一併刪；至少留一節）、底部 ＋節／＋獨立頁。跨節複製貼上可用。

## 浮水印（文件層＋節覆寫）

文字或資料綁定（key 有值時取代文字，例：status=作廢）、字級、顏色、旋轉角度（滑桿）、滿版平鋪（水平/垂直間隔）、圖層（內容下方/上方）。圖層為上方時，勾了「置於浮水印之上」的元素仍蓋在浮水印之上。

## 固定範圍數值的輸入

旋轉角度等固定範圍數字用「滑桿＋數字輸入」組合。

## 填寫模式（嵌入 fill）與可填欄位標記

給宿主的終端使用者用的受限編輯：**只能改被設計者標記的欄位，版面完全鎖死**。權限由 embed token 的 mode 決定（見 [embed.md](embed.md)），前端只是照後端給的能力畫 UI。

- **標記可填欄位**（設計模式）：選中**文字元素**或**表格的 text 儲存格** → 屬性面板勾「允許在填寫模式修改」。多選時一次勾起來。畫布上被標記的欄位顯示**綠色虛線**（文字元素含容器內的巢狀元素為外框、儲存格為格線＋淡綠底）。
- **大綱變成「待填欄位」清單**：填寫模式的左側大綱只列出改得到的欄位；表格**展開成逐格項目**（只列真的能填的格，空白格顯示「（空白）第 N 列第 M 欄」），點下去連座標一起選取、右側立刻是那一格的輸入框。空的 band 分組不顯示；沒有任何可填欄位時顯示提示。
- **填寫模式（mode=fill）看到的介面**：沒有元件盤、沒有右鍵選單、沒有節新增/刪除、沒有大綱的刪除/複製/鎖定/隱藏按鈕、沒有樣板JSON與驗證分頁、樣板名稱唯讀。屬性面板只剩「內容」一欄（沒有座標/樣式/紙張/浮水印），右側也沒有「資料」分頁。畫布上只有可填的元素選得到，表格為了讓人點進格子仍可選中、但只有可填的格能編輯（且只做單格選取，不能框選範圍）；拖曳與縮放一律無效。
- **唯讀模式（mode=view）**：以上全部再加「不能改內容」，右上角顯示「👁 唯讀」、沒有儲存鈕。
- **儲存**：填寫模式按儲存走 `PATCH /api/templates/:id/values`，只送可填欄位的值。
- **存檔不清空復原歷史**：儲存後只同步伺服器指派的 id／updatedAt，不重載整份文件——存完才發現改錯還退得回去。
- **不可新增資料綁定**：填寫的內容不能出現樣板原本沒有的 `{{key}}`（後端拒絕）——避免填寫者用它讀出宿主 render 資料裡未綁定的欄位。**原本就在的綁定不受影響**：設計者可以把「收款單 `{{customer.name}}`」這種欄位標成可填，填寫者改前後文時原綁定會原樣保留。（擋「含有」而不是「新增」的話，這種欄位永遠存不了，而且會因為送出時是整批驗證而讓填寫者完全存不了任何東西。）要新增資料綁定請在設計模式的文字內容裡加 `{{key}}`。

> 前端的這些限制是體驗層；真正的強制在後端（capability 逐端點檢查＋窄 API 只寫得到被標記的欄位）。所有結構性變更在前端也統一經過 `EditorStateService.record()` 這個單一守衛，不是逐個 UI 補判斷。
